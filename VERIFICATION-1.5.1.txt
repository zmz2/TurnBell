Regression coverage added for 1.5.1
- A completion during Windows lock is queued in extension session storage and
  recreated after unlock with the same notification ID or Web Notification tag.
- Replays use a generic message and the queue omits page title, URL, fingerprint,
  and reply text.
- The original active notification is cleared before replay, avoiding duplicate
  notifications when the operating system has not already removed it.
- Unlock racing the original notification still produces one replay.
- A failed replay remains queued for a later unlock or extension startup.
