# Security Policy

## Supported version

Security fixes are currently applied to the latest published TurnBell version.

## Reporting a vulnerability

Use GitHub's private security advisory feature when available. If that is not possible, open a minimal issue asking for a private contact channel, without publishing exploit details, account data, tokens, cookies, or private conversations.

Useful reports include:

- affected TurnBell version;
- affected Edge and Windows versions;
- reproduction steps using non-sensitive test data;
- expected and observed behavior;
- whether the issue could expose conversation text, settings, browser data, or credentials.

TurnBell should never require account credentials, Cookie access, remote scripts, or a local listening service.
